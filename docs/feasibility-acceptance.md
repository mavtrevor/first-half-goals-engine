# Offline-subset feasibility decision

17 October 2026. User approved direct execution of the written plan.

**Accepted scope:** a local offline research application using already saved factual score snapshots under the provider's published ODbL notice. The ODbL grants use, copying and derivative-database rights; the source notice and license URI are retained. This decision does not certify separate live API access conditions or source accuracy.

The earlier blanket build hold has been narrowed: offline ingestion, tests and explicitly unvalidated retrospective experiments can be constructed; operational forecasts and external integration remain locked. The reasoning and cost of this ruling are recorded in the execution ledger and handoff. No remaining gate below is represented as passed.
