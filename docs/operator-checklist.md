# Manual Nigeria verification checklist

This application never logs into SportyBet or creates codes. It stores a human record only.

Before recording an observation, personally open the official Nigeria interface and confirm: real senior football; exact competition/teams/home-away order; date, kickoff and timezone; pre-match status; **1st Half / Match Total Goals / Over 0.5**; active or suspended availability; actual decimal price and observation time. Team-total, full-time, corners, “rest of half,” virtual and other-country markets are different products and are excluded.

Current Nigeria settlement provisions, including stoppage time, interrupted/resumed fixtures and first-half settlement, still need independent verification. Other countries' rules cannot fill that gap. The form cannot override the policy's unverified-rules state.

If you independently create a booking code in SportyBet's official interface, paste the actual code and exact selection manifest here. A pasted code starts unverified. Personally reload it in Nigeria's official interface, compare every leg/period/line/outcome, and separately record the complete reloaded selection set. Missing or changed legs are a mismatch. Unknown expiry stays unknown; the current form does not infer code validity from its format.

Five-minute quote expiry and changed kickoff/snapshot identity invalidate current observations. A saved reload-match flag describes that past human check; it does not prove current availability, current prices, operator acceptance or wager placement. Readiness remains blocked in this build even after a matching reload.

Do not enter passwords, OTPs, phone numbers, cookies or payment details. No wager action is part of this checklist. Adult users should keep personal limits and respect operator self-exclusion; the app supplies no alternate-account or loss-chasing route.
